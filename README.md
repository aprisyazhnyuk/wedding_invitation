# Диана и Антон · 07.11.2026

Сайт для GitHub Pages и анкета с записью в частную Google Sheets. Обложка, программа с линией времени и содержание сохранены. Ничего устанавливать на компьютер и собирать перед публикацией не нужно.

## 1. Создать репозиторий

На https://github.com/new создайте репозиторий `wedding_invitation` в аккаунте `aprisyazhnyuk`. Для бесплатного GitHub Pages выберите **Public**, добавьте README. Репозиторий уже создан: https://github.com/aprisyazhnyuk/wedding_invitation. Включение Pages необходимо выполнить в настройках GitHub.

Альтернатива: распакуйте архив и загрузите его содержимое через **Add file → Upload files**. Папки `docs` и `google-apps-script` должны оказаться непосредственно в корне репозитория. Не загружайте архив одним файлом. Если браузер пропустит скрытый `.nojekyll`, сайт из обычных HTML/CSS/JS всё равно сможет публиковаться.

## 2. Подготовить Google Sheets

1. Откройте https://sheets.new и назовите таблицу «Свадьба — ответы гостей».
2. Не открывайте доступ «всем по ссылке». Через «Поделиться» добавьте Диану при необходимости.
3. В таблице откройте **Расширения → Apps Script**.
4. Замените содержимое `Code.gs` кодом из `google-apps-script/Code.gs`, сохраните проект.
5. Вверху файла проверьте `ALLOWED_ORIGIN`. Для вашего аккаунта это `https://aprisyazhnyuk.github.io` — без пути `/wedding_invitation/` и без завершающего слеша. Если позже подключите собственный домен, обновите эту строку и развертывание.
6. Выберите функцию `setup` и нажмите **Выполнить**. Дайте скрипту разрешение работать с вашей таблицей. Он создаст лист «Ответы гостей», заголовки и оформление; повторный запуск не стирает ответы. Часовой пояс для отображения дат сейчас Москва, при необходимости измените строку `Europe/Moscow`.
7. Нажмите **Развернуть → Новое развертывание → Тип: Веб-приложение**.
8. **Выполнять от имени: меня**. **У кого есть доступ: Все / Anyone**, включая пользователей без входа в Google. Это доступ к обработчику отправки; сама таблица остаётся частной. Если корпоративный Google-аккаунт не предлагает такой доступ, используйте личный аккаунт.
9. Нажмите «Развернуть» и скопируйте URL веб-приложения вида `https://script.google.com/macros/s/…/exec`. Нужен `/exec`, не тестовый `/dev` и не адрес таблицы.
10. Пришлите URL обработчика — я вставлю его в `docs/config.js`. Или вставьте самостоятельно между кавычками в `appsScriptUrl: ''`.

Ссылки на таблицу и редактор скрипта публиковать в репозитории не требуется. Пароли, ключи доступа и сами ответы туда не загружаются. URL `/exec` является публичным адресом приёма анкет, а не секретом.

## 3. Включить GitHub Pages

В репозитории откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/docs`, затем **Save**. После успешной публикации приглашение будет доступно по адресу:

https://aprisyazhnyuk.github.io/wedding_invitation/

Этот адрес пока планируемый: Pages необходимо включить в настройках репозитория. После каждого изменения файлов в `main/docs` GitHub обновляет сайт. Собственный домен необязателен.

## 4. Проверить перед рассылкой

После подключения обработчика проверка реальной записи обязательна. Пока проверены локальные файлы и логика сохранения; работа опубликованного Google-обработчика ещё не проверена.

- В приватном окне браузера, без входа в Google, отправьте тестовую анкету «Роспись и ресторан»: несколько напитков, аллергия «Да», продукты и ограничения. Убедитесь, что появилась строка в таблице и только затем сообщение об успехе.
- Нажмите «Изменить ответ», измените напитки и отправьте. Должна обновиться та же строка.
- Нажмите «Заполнить за другого гостя» и проверьте варианты «Только роспись», «Только ресторан», «Не смогу прийти». Данные ресторана не должны оставаться у первых и последнего вариантов.
- Попробуйте отправить «Аллергии: Да» без продуктов — сайт должен попросить заполнить поле.
- Отключите сеть и отправьте: сообщение об успехе не должно появляться. После восстановления связи повторите отправку в этой же вкладке — должна остаться одна строка.
- Проверьте на телефоне и в сети, из которой гости будут открывать приглашение. Доступность GitHub и Google зависит от сети.
- Удалите тестовые строки из таблицы, оставив заголовок.

После публикации изменений Apps Script выберите **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**. Простое сохранение кода не обновляет рабочий `/exec`.

## Как это работает

`docs/index.html` — содержание страницы. `docs/style.css` — оформление. `docs/app.js` — поведение анкеты. `docs/config.js` — адрес обработчика. `docs/assets` — обложка и локальные шрифты с лицензией. `google-apps-script/Code.gs` — проверка данных и запись в таблицу.

Сайт отправляет POST через скрытый iframe. Google возвращает подтверждение после записи; сайт проверяет домен Google и случайный идентификатор запроса. Так отправка не зависит от чтения ответа `fetch` между разными доменами. Неподтверждённая отправка не считается успешной. При тайм-ауте запись могла успеть сохраниться — повтор в той же вкладке безопасно обновит её.

Служебный ключ для обновления ответа хранится только в текущей вкладке; в таблицу записывается его хеш, колонка скрыта. После перезагрузки страницы создаётся новая анкета. Исправление старого ответа после закрытия вкладки — через организаторов. Совпадение имён не объединяет разных гостей.

Ответы не читаются публичным обработчиком. Гости пишут без регистрации, поэтому сама ссылка не удостоверяет личность отправителя. Разрешённый адрес сайта проверяется, но не является паролем. Таблицу держите закрытой и используйте только для организации свадьбы. Название листа, порядок заголовков и скрытую служебную колонку не меняйте: обработчик опирается на них.

Дедлайн указан в тексте, но анкета не закрывается автоматически 24 октября. Пока остаются согласованные заглушки для ЗАГСа и ресторана. Перед рассылкой их нужно заменить.
